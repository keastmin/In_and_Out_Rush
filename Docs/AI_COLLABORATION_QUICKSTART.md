# ProjectIO AI 협업 기능 작업 빠른 시작

## 작업자가 하는 일

1. 에이전트가 요청하면 최신 변경을 Pull한다.
2. 에이전트가 만든 Active 문서를 Commit·Push하고 완료 사실을 알려준다.
3. 구현 후 필요한 Unity 플레이 테스트와 최종 결과를 확인한다.

상대 작업자의 Active 예약을 별도로 승인하거나 Project Map과 기능 문서를 매번 직접 읽고 수정할 필요는 없다.

## 에이전트가 하는 일

```text
자연어 기능 요청
→ 원격 변경 확인
→ Pull 필요 시 작업자에게 알리고 중단
→ 기존 Active 예약과 요청 범위 비교
→ 충돌 시 겹치는 범위를 알리고 중단
→ 충돌이 없으면 Active 문서 작성
→ 작업자에게 Active 문서 Push 요청
→ Push 완료 후 원격 예약 존재와 새 변경 확인
→ 충돌이 없으면 구현
→ 검증·관련 기능 문서 갱신·Completed 이동
```

## 에이전트가 멈추는 경우

- Pull할 원격 commit이 있음
- 로컬 미커밋 변경이나 Push되지 않은 commit이 있음
- 기존 Active 예약과 코드, Asset 또는 공용 연결부가 겹침
- 자신의 Active 문서가 원격에서 확인되지 않음
- 구현 중 예약하지 않은 공용 파일이나 Asset이 추가로 필요함

이 경우에만 작업자에게 필요한 조치를 알려준다. 일상적인 구조 조사, 문서 작성과 문서 갱신은 에이전트가 처리한다.

## 협업 전제

두 작업자는 Active 문서가 보이는 동일한 공용 upstream 브랜치를 사용해야 한다. 서로 다른 브랜치에만 Active 문서를 Push하면 상대 작업의 예약을 확인할 수 없다.
