# 몬스터 기획

## 공통 분류

- 외부 몬스터는 개척지에서 러너와 사선을 위협한다.
- 내부 몬스터는 타워나 러너를 공격하지 않고 중앙 트랙을 따라 이동만 한다.
- 일반 내부 몬스터가 트랙을 완주하면 러너에게 체력 10의 피해를 준다.
- 정예 내부 몬스터가 웨이브 종료까지 살아남으면 러너에게 체력 30의 피해를 준다.
- 보스 내부 몬스터가 트랙을 완주하면 러너 최대 체력의 50%만큼 피해를 준다.
- 일반·보스 몬스터의 완주 피해는 각 몬스터가 완주한 순간마다 따로 적용한다.
- 웨이브 종료 시 생존한 정예 몬스터의 피해는 모두 합산한다.
- 피해 감소는 완주·합산 피해 계산이 끝난 뒤 마지막에 적용한다.

## 외부 몬스터의 영역 편입

- 라플라시아를 제외한 외부 몬스터는 영역에 편입되는 즉시 정예 내부 몬스터가 된다.
- 전투 중 편입되면 내부 몬스터 소환 지점에서 즉시 등장한다.
- 정비 시간 중 편입되면 다음 웨이브 시작 시 내부 몬스터 소환 지점에서 등장한다.
- 기간티아를 최종 처치하면 토큰 1개를 획득한다.
- 기간티아 외 내부화 몬스터는 처치 시 약 30% 확률로 토큰 1개를 떨어뜨린다.

## 외부 몬스터

### 기간티아

- 개척지를 배회하는 지네 형태 몬스터다.
- 기본 이동속도의 2배로 이동한다.
- 기본 무기만 사용했을 때 목표 처치 시간은 초반 1분 이상, 중반 1분 미만, 후반 약 30초다.

### 스토커

- 기본 이동속도의 1.5배로 러너를 추격한다.
- 2초마다 공격 시점의 러너 위치를 향해 직선 투사체를 발사한다.
- 투사체는 기본 이동속도와 같은 속도로 이동한다.

### 스트라이더

- 소금쟁이 형태로 개척지를 배회한다.
- 일정 속도 보행 대신 순간적인 고속 이동을 사용한다.

### 라플라시아

- 한 자리에 고정된 대형 꽃 형태의 탄막 몬스터다.
- 0.75초마다 투사체를 발사한다.
- 공격 형태는 8자, 십자, 회오리, 사각, 8자 순서로 반복한다.
- 영향 범위 안에서 러너가 개척을 시작하면 라플라시아 투사체는 사선에 피해를 주지 못한다.
- 영역에 편입되어도 정예 내부 몬스터로 바뀌지 않는다.

## 내부 몬스터

### 워커

- 일반 웨이브의 수량 압박을 담당하는 기본형이다.

### 프레데터

- 높은 체력으로 타워 화력을 오래 분산시키는 정예형이다.

### 인베이더

- 보스 웨이브에 등장하는 보스형이다.
- 생화학 센터 타워의 반전 효과에 면역이다.

### 하드워커

- 러너가 직접 전투에 가담하도록 유도하는 보너스형 특수 몬스터다.

## 반전 상태

- 반전된 일반 몬스터는 원래 이동 방향을 유지하고 별도의 공격 행동을 하지 않는다.
- 반전은 제한시간 없이 대상이 죽을 때까지 유지된다.
- 반전된 몬스터가 트랙을 완주하면 원래 해당 몬스터가 러너에게 줄 피해량만큼 러너 체력을 회복한다.
- 보스 몬스터에는 반전이 적용되지 않는다.
