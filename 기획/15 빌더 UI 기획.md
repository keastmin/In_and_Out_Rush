# 빌더 UI 기획

## 상시 정보

### 화면 중앙 상단

- 전체 게임 시간, 현재 웨이브 남은 시간과 정비 시간을 표시한다.
- 러너의 현재·최대 체력을 함께 표시한다.

### 화면 중앙

- 현재 건설 또는 관리 명령을 안내한다.
- 설치 불가, 자원 부족, 정비 시간 아님과 최대 개수 도달 등 실패 이유를 즉시 표시한다.

### 화면 중앙 하단

- 건설 가능한 타워 종류, 비용과 해금 상태를 표시한다.

### 화면 오른쪽 상단

- 보유 유물과 광물, 가스, 토큰을 표시한다.

### 화면 오른쪽 중단

- `Tab`으로 타워 피해량 그래프를 열고 닫는다.

### 화면 오른쪽 하단

- 러너, 연구소, 영역, 사선, 트랙, 성역, 관문과 주요 위험을 나타내는 미니맵을 표시한다.

## 건설과 관리 피드백

- 설치 전에 타워 범위, 비용, 설치 가능 여부와 트랙 확장 위험을 표시한다.
- 속성 부여가 무작위임을 실행 전에 알리고 결과를 즉시 보여준다.
- 판매 전 환수액, 이전 전 비용과 가능 시간, 범위 선택 시 대상 수와 총비용을 표시한다.
- 트랙 확장 5초 전 메시지를 표시하고, 확장 뒤 무료 이전 가능한 타워를 구분한다.

## 빠른 정보 이동

- `R`: 연구소 화면
- `Space`: 러너 정보 화면
- `Ctrl`: 중앙 연구소 위치
- 타워·몬스터·유물 선택: 대상 상세 정보
