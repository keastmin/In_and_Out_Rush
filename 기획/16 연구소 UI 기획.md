# 연구소 UI 기획

## 진입

- 빌더가 `R`을 누르거나 연구소를 선택해 연다.
- 화면을 연 동안에도 웨이브 시간과 러너의 치명 위험을 계속 확인할 수 있어야 한다.

## 상위 분류

1. 타워 업그레이드
2. 러너 업그레이드
3. 아이템·무기 구매
4. 토큰 상점
5. 유물 관리

## 구매 정보

- 현재 단계와 효과
- 다음 단계 효과와 비용
- 최대 단계
- 보유 자원
- 해금 조건과 구매 불가 이유
- 첫 구매의 `N=0` 적용 결과

## 유물 관리

- 이름, 설명, 적용 범위와 활성 가능 여부를 표시한다.
- 유대 활성화 범위 약 10×10타일과 현재 적용 대상을 보여준다.
- 활성화 전 유물에만 판매 기능을 제공하고 엑셀 `Artifact` 시트의 판매 토큰 수를 예상 획득량으로 표시한다.

## 보급 대기열

- 구매한 아이템·무기의 대상, 수량과 전달 순서를 표시한다.
- 러너의 현재 장비와 아이템별 최대 소지량을 함께 표시한다.
- 전체 보급품 구매 한도 10개와 남은 수량을 보여준다.
- 한도 도달 시 구매 버튼을 비활성화하고 기존 보급품을 폐기·교체·환불할 수 없음을 안내한다.

## 토큰 상점

- 왜곡 깃발, 격리 깃발, 나침반, 지도와 소울 메이트 뱃지를 목록으로 표시한다.
- 각 상품의 토큰 가격, 일반·특수 분류, 구매 가능 시점과 판당 구매 제한을 표시한다.
- 지도는 25분부터 판당 1회만 구매할 수 있다.
- `냉전` 유물로 일반 토큰 상품이 비활성화되면 구매 불가 사유를 표시한다.
