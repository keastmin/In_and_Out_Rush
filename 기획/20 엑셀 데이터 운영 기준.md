# 엑셀 데이터 운영 기준

## 두 자료의 역할

- Markdown 기획서는 기능의 목적, 작동 순서, 플레이 결과, 예외 상황과 다른 기능과의 관계를 설명한다.
- `땅타 프로젝트 데이터 테이블 0.50v.xlsx`는 비용, 확률, 지속시간, 수량, 배수, 생성 개수와 웨이브 시간표처럼 표로 조정하기 쉬운 데이터만 관리한다.
- 엑셀의 짧은 설명은 행의 의미를 구분하기 위한 요약이며 상세 기능 설명을 대신하지 않는다.

## 정보 확인 순서

1. 담당 기능의 Markdown 문서에서 전체 작동 방식과 예외를 확인한다.
2. 문서에 적힌 엑셀 시트에서 현재 수치와 상태를 확인한다.
3. 값이 `질문 필요` 또는 `추후 입력`이면 임의로 확정하지 않고 [기획자 확인 질문](90%20%EA%B8%B0%ED%9A%8D%EC%9E%90%20%ED%99%95%EC%9D%B8%20%EC%A7%88%EB%AC%B8.md)을 확인한다.

## 엑셀 상태값

- `확정`: 현재 구현 기준으로 사용할 수 있는 값이다.
- `임시`: 플레이 테스트를 위한 최초값이며 밸런스 결과에 따라 바꿀 수 있다.
- `질문 필요`: 서로 충돌하거나 계산 방법이 부족해 기획 답변이 필요하다.
- `추후 입력`: 기능 방향은 정해졌지만 세부 데이터 작성이 뒤로 예정된 항목이다.
- `보류`: 현재 콘텐츠 목록에는 남겨 두지만 사용하지 않는 항목이다.

## 수정 원칙

- 숫자만 바꾸는 밸런스 조정은 엑셀에서 먼저 수정한다.
- 숫자 변경으로 플레이 결과나 규칙이 달라지면 관련 Markdown 설명도 함께 수정한다.
- 새 기능을 추가할 때에는 Markdown에 상세 기획을 먼저 작성하고 엑셀에 고유 ID와 조정값을 추가한다.
- 같은 값은 한 시트에서만 원본으로 관리하고 다른 시트의 집계값은 수식으로 참조한다.
- `9999`, `?`, `null` 같은 임시 표시는 사용하지 않고 빈 셀과 상태값으로 구분한다.

## 현재 엑셀 시트

- `README`: 사용법, 상태값과 시트 안내
- `Global`: 판 전체의 공통 시간·인원·승패 수치
- `Runner`: 러너 조작과 능력치
- `Economy`: 자원 생성량과 업그레이드·상점 가격
- `Tower`: 센터·공격·지원 타워 수치
- `Attribute`: 속성 확률과 속성 효과
- `Item`, `Skill`, `Weapon`: 러너 장비 데이터
- `Monster`: 몬스터 분류, 이동과 실패 피해
- `Wave`: 웨이브별 정규화된 등장 시간표
- `Map`: 지역, 성소, 지형과 스테이지 배치
- `Artifact`: 현재 유물 목록과 효과 수치
- `Validation`: 자원 총량과 데이터 상태 점검
