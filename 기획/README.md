# 땅타 프로젝트 기획 패키지

이 폴더는 **기획서와 데이터 테이블을 분리한 2체제**로 운영한다.

## 01. 기획서

`기획서/`는 게임의 기능과 규칙을 설명하는 기준이다.

- 기능 목적
- 작동 순서
- 플레이 결과
- 예외 처리
- 시스템 간 관계
- 아직 결정되지 않은 범위

개발자는 기능을 이해할 때 먼저 이 폴더를 확인한다.

## 02. 데이터

`데이터/땅타 프로젝트 데이터 테이블 0.60v.xlsx`는 숫자 조정용 원본이다.

- 비용
- 피해량
- 확률
- 지속시간
- 재사용 시간
- 이동속도
- 배수
- 수량
- 생성량
- 웨이브 등장 시각
- 맵 배치량

숫자 밸런스를 수정할 때는 기획서의 문장을 반복해서 수정하지 않고 Excel의 원본 행을 수정한다.

## 03. 질문

`질문/90 기획자 확인 질문.md`는 아직 플레이 결과가 여러 방식으로 해석될 수 있는 항목만 관리한다.

답변이 들어오면:
1. 기능 설명은 담당 Markdown에 반영
2. 수치 데이터는 담당 Excel 시트에 반영
3. 질문을 `답변:` 상태로 변경
4. 더 이상 필요한 결정만 다음 질문으로 남긴다.

## 추가 기획안 편입

별도로 들어온 다음 문서의 내용은 원문 파일을 별도 문서로 유지하지 않고 담당 기획서에 편입했다.

- `벌레지옥.txt` → `기획서/04 영역 사선 자원 기획.md`, `05 맵 및 레벨 디자인.md`
- `라플라시아.txt` → `기획서/07 몬스터 기획.md`
- `몬스터 추가 기획.txt` → `기획서/07 몬스터 기획.md`

## 이번 개편 핵심

- 기획자 질문지의 답변을 관련 기획서와 Excel에 반영
- 중복되거나 충돌하던 유물 중복 규칙 정리
- 속성 3개 묶음 보너스와 센터 확률 재분배 규칙 반영
- 주파력 30 → 60 → 90 → 120 단계 확정
- 배송 로켓의 보급 예외 및 유물 강화값 반영
- 벌레지옥과 라플라시아의 별도 추가 기획 편입
- 8~10웨이브, 무기/몬스터/타워 상세 전투값은 임의 확정하지 않고 질문으로 유지
- Excel에 `ChangeLog`를 추가하고 상태값을 `확정/임시/상정/질문 필요/추후 입력/보류`로 구분
