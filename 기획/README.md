## 갱신 방법

1. [기획자 확인 질문](90%20%EA%B8%B0%ED%9A%8D%EC%9E%90%20%ED%99%95%EC%9D%B8%20%EC%A7%88%EB%AC%B8.md)의 빈 답변란에 기획 답변을 작성한다.
2. 다음 정리 요청 때 답변을 담당 문서와 핵심 기획에 반영한다.
3. 답변하지 않은 질문은 본문에 추측으로 넣지 않는다.
4. 코드 구조나 기술 선택이 아니라 플레이 경험, 규칙, 수치, 화면 정보만 기획자가 결정한다.
5. 기능의 의미와 예외는 Markdown에서 수정하고, 같은 기능의 숫자만 바꿀 때는 엑셀에서 수정한다.
