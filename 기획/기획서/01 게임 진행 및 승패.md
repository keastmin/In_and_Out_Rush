# 게임 진행 및 승패 기획

## 세션 구성

- 러너 1명과 빌더 1명이 한 팀으로 플레이한다.
- 역할은 로비에서 선택한다.
- 전투 구간과 정비 구간이 반복된다.
- 정비·웨이브와 관계없이 러너의 외부 이동·개척·전투는 계속된다.
- 한 플레이어가 이탈하면 다른 플레이어의 진행을 정지하고 재접속 또는 종료를 선택하게 한다.

## 승리 흐름

1. 시작 영역에서 출발한다.
2. 러너가 영역과 성역을 확보한다.
3. 빌더가 타워와 업그레이드로 내부 몬스터를 방어한다.
4. 성역 할당량을 충족한다.
5. 관문이 활성화된다.
6. 러너가 관문을 통과하면 즉시 승리한다.

성역은 여러 구역으로 나뉠 수 있으며 확보 면적을 합산한다. 할당량 자체는 `Global`의 단일 값으로 관리한다.

## 패배 흐름

패배는 러너의 최종 체력 사망 또는 자기 사선 교차의 치명 판정이 방지되지 않은 경우 발생한다.

피해 처리의 공통 순서는 다음을 따른다.

1. 개별 피해 또는 완주 피해 계산
2. 여러 정예의 웨이브 종료 피해 합산
3. 피해 감소 적용
4. 러너 체력 반영
5. 체력 0 여부에 따른 사망 판정

## 사망 방지

- 자기 사선 교차에는 생명선이 우선적으로 자동 발동한다.
- 생명선은 일반 체력 피해로 체력이 0이 되는 경우에는 발동하지 않는다.
- 불씨앗을 보유하면 사망 시 1회 부활한다.
- 부활 또는 생환이 발생하면 진행 중인 사선은 취소된다.
- 부활 후 장비와 역할 상태는 유지한다.

## 내부 몬스터 실패 피해

- 일반 몬스터는 트랙 완주 시 개체별 피해를 준다.
- 정예 몬스터는 웨이브 종료까지 생존한 개체의 피해를 합산한다.
- 보스 몬스터는 트랙 완주 시 최대 체력 비율 피해를 준다.
- 피해량의 기준값은 `Monster` 시트가 원본이다.
