# 플레이어 러너 상세 기획

## 역할 목표

러너는 PC 키보드·마우스로 조작하는 3인칭 액션 캐릭터다. 외부 개척지를 직접 이동하고 전투하면서 사선을 닫아 영역, 자원, 성역 진로와 관문 접근로를 확보한다.

## 장비 구성

- 1번 슬롯에는 무기 한 종류를 장착한다.
- 2~4번 슬롯에는 소모품을 배치하며 소모품끼리 슬롯을 교환할 수 있다.
- 스킬은 한 종류만 장착한다.

## 이동과 조작

- `W`, `A`, `S`, `D`: 이동
- 마우스: 바라보는 방향과 아이템·스킬 사용 방향 결정
- 마우스 왼쪽 버튼: 현재 무기의 기본 공격
- `Q`: 선택한 소모품 또는 현재 무기의 특수 기능
- `E`: 장착 스킬
- `F`: 개척지·영역 오브젝트 상호작용
- `Alt`와 마우스: 스마트 핑
- `Space`: 중앙 연구소 기준 정보와 획득 유물 확인
- 게임패드는 지원하지 않는다.

## 지형 충돌

- 맵 끝과 자연 지형에 수직으로 부딪히면 위치 이동은 멈추지만 현재 이동·대시 판정은 유지된다.
- 대시를 유지한 채 정면으로 벽에 막히면 움직이지 않는 동안에도 기력이 계속 소모된다.
- 맵 끝이나 자연 지형에 대각선으로 부딪히면 벽을 뚫지 않고 벽면을 따라 좌우 방향으로 미끄러지듯 이동한다.
- 몬스터 트랙은 이동을 막는 벽으로 취급하지 않는다.

## 대시

- `Shift`를 누르는 동안 사용한다. 설정에서 유지형과 토글형을 선택할 수 있게 한다.
- 이동속도는 기본의 150%다.
- 유지 중 기력을 초당 12.5 소모한다.
- 대시 비용을 감당할 기력이 있을 때만 시작할 수 있다.

## 슬라이드

- `Ctrl`로 사용한다.
- 시작 순간 기본 이동속도의 300%로 가속한 뒤 100%까지 감속한다.
- 기본 이동 거리는 2.5m이고 기력 35를 소모한다.
- 경사와 공중 사용 상황은 맵에 존재하지 않는다.
- 벽과 충돌하면 즉시 정지한다.

## 기력

- 기본 기력은 100, 성장 최대치는 200이다.
- 기본 회복량은 초당 8.333이고 강화 후 최대 초당 16.66이다.
- 대시나 슬라이드를 멈춘 직후부터 별도 지연 없이 회복한다.
- 기력 소모 행동은 현재 기력이 비용 이상일 때만 사용할 수 있다.
- 피격·개척 중에도 회복 규칙은 달라지지 않는다.
- 각성 상태에서는 기력이 항상 최대치로 유지된다.

## 체력과 전투 수치

- 기본 체력은 300, 성장 최대치는 600이다.
- 피해 감소는 기본 0%, 최대 50%다.
- 무기 공격력은 모든 무기에 공통 적용되는 배수이며 기본 1배, 성장 최대 20배다.

## 주파력과 개척

- 기본 주파력은 30m다.
- 영역 경계에서 마우스 오른쪽 버튼으로 개척을 시작한다.
- 개척 중에는 러너의 이동 경로를 사선으로 표시한다.
- 동시에 진행할 수 있는 사선은 러너를 따라가는 한 개뿐이다.
- 러너가 기존 영역으로 복귀하거나 생환·부활하면 진행 중인 사선을 종료한다.
- 주파력을 모두 사용하면 탈진 상태가 되어 총 이동속도가 50% 감소한다.
- 생분해 장치가 활성화된 동안에는 주파력 상한을 적용하지 않는다.
- 외부 몬스터와 투사체가 사선을 공격하면 러너 체력이 직접 감소한다.
- 자기 사선과 교차하면 생명선 또는 불씨앗 부활이 없을 때 즉사한다.

## 시점과 중앙 정보

- 러너 카메라는 3인칭이다.
- 중앙 정보의 시야 반경은 몬스터 트랙 단계에 따라 15m, 30m, 45m, 60m로 증가한다.
