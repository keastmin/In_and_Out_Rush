# 영역·사선·자원 기획

## 1. 공간 정의

- **개척지:** 러너가 외부 몬스터와 환경을 상대하며 영역을 확장하는 중립 공간.
- **영역:** 팀이 확보한 공간. 빌더가 타워를 설치할 수 있다.
- **성역:** 관문 해제를 위한 목표 공간. 여러 조각을 합산해 할당량을 계산한다.
- **몬스터 트랙:** 내부 몬스터가 이동하는 독립 공간.
- **관문:** 성역 할당량 충족 후 러너가 통과하는 최종 목표.

## 2. 기본 사선 흐름

1. 러너가 기존 영역 경계에서 개척을 시작한다.
2. 출발점 이후의 이동 경로가 사선으로 저장된다.
3. 러너가 자기 사선을 밟지 않고 기존 영역으로 돌아온다.
4. 기존 영역 경계와 사선이 닫은 내부를 새 영역으로 편입한다.
5. 새 영역에 포함된 자원과 대상 오브젝트의 영역 편입 규칙을 적용한다.

동시에 진행되는 사선은 하나다. 사선의 세부 위험 판정은 현재 진행 중인 사선과 자기 사선 교차 규칙을 기준으로 한다.

## 3. 벌레지옥

벌레지옥은 외부 개척지에 배치되는 적대 지형이다. 전체 범위와 실제 발동 범위가 분리되며, 발동 후 러너를 중심부 방향으로 끌어당긴다.

발동 시점에는 러너의 위치를 포인트(1)로 저장한다. 이후 러너가 전체 범위에서 빠져나가거나 폭파 피해를 받는 시점에 현재 위치를 포인트(2) 또는 포인트(3)으로 저장하고, 포인트(1)과 연결하는 사선을 자동 생성한다.

자동 생성된 사선이 기존 사선과 교차하면 일반적인 사선 교차 판정을 적용한다. 자동 사선 생성 직후부터는 정상적인 사선 판정을 적용한다.

현재 벌레지옥의 거리·속도·폭파 수치는 모두 **임시 밸런스 데이터**이며 별도 데이터 시트에서 관리한다.

## 4. 자원 획득

- 자원은 러너가 직접 줍는 방식이 아니라 자원이 포함된 땅을 영역화하면 획득한다.
- 획득 즉시 팀 공용 자원에 합산한다.
- 자원은 재생성하지 않는다.
- 소형·중형·대형의 실제 가치와 생성 개수는 `Economy` 시트가 원본이다.
- 1스테이지 전체 총량은 최초 플레이 테스트용 값이며 섹터 단위의 적정량은 추가 검토가 필요하다.

## 5. 자기 사선과 생존

- 자기 사선 교차는 치명 판정이다.
- 생명선은 자기 사선 교차에 자동 발동한다.
- 생명선이 없고 불씨앗 등 다른 부활 수단도 적용되지 않으면 패배한다.
- 생환·부활 시 진행 중인 사선은 취소한다.

## 6. 탈진

주파력이 소진되면 탈진 상태가 되어 총 이동속도가 감소한다. 주파력의 기본값과 성장 단계는 `Runner` 시트에서 관리하며, 생분해 장치가 활성화된 동안에는 주파력 상한을 적용하지 않는다.
