# 맵 및 레벨 디자인 기획

## 1. 맵 구성 원칙

맵은 동일 크기의 정사각형 섹터를 기본 단위로 구성한다. 무작위 콘텐츠는 전체 맵에서 바로 추출하지 않고, 지정된 섹터 범위 안에서 배치한다.

### 중앙 고정 요소

- 중앙 연구소
- 시작 영역
- 몬스터 트랙

### 판별 배치 요소

- 외부 몬스터
- 벌레지옥
- 자연 지형
- 성소
- 유물
- 관문

## 2. 배치 규칙

- 자연 지형은 섹터 단위 기본 배치 규칙을 따른다.
- 벌레지옥은 시작 영역과 다른 벌레지옥 사이의 최소 거리 규칙을 적용한다.
- 벌레지옥은 성역과 겹치지 않는다.
- 자원은 별도의 최소 거리 제한을 두지 않는다.
- 관문은 후보 지점 중 하나를 선택한다.
- 실제 생성 개수는 `Map` 시트에서 관리한다.

## 3. 벌레지옥

벌레지옥은 단순 장애물이 아니라 러너의 이동 경로와 사선 생성 자체를 위험하게 만드는 적대 지형이다.

- 전체 범위와 발동 범위가 별도로 존재한다.
- 발동하면 러너를 중심부 방향으로 끌어당긴다.
- 발동 중에는 일정 조건이 충족될 때까지 정상적인 사선이 생성되지 않고 발동 시점의 이동 경로가 저장된다.
- 범위를 벗어나거나 폭파 피해를 받으면 저장 위치와 현재 위치를 연결한 사선이 생성된다.
- 자동 사선도 일반 사선 교차 판정을 적용한다.

거리·흡입·폭파 피해 등의 수치는 임시값으로 `벌레지옥` 데이터에서 관리한다.

## 4. 성역과 성소

성역은 '성소 개수'가 아니라 영역화된 면적으로 관문 해제 진행률을 계산한다.

성소는 개별 효과 오브젝트다.

- 한 판에 일정 범위의 성소가 무작위 생성된다.
- 각 성소는 하나의 고유 효과를 제공한다.
- 성소가 발동하면 해당 위치가 임시 영역으로 유지된다.
- 즉시 보상을 제공하는 성소도 **보상 지급과 임시 영역의 유지 여부를 분리**한다. 보상을 받았다고 해서 임시 영역이 즉시 소멸하지 않는다.
- 성소의 구체적 지속·소멸 규칙은 해당 성소 데이터와 기능 문서를 따른다.
- 발동하지 않은 성소가 일반 영역에 편입되면 사라진다.

### 성소 목록

- 오아시스: 러너 체력 회복
- 사원: 무작위 아이템 또는 무기 지급
- 제단: 일정 시간 각성
- 탑: 토큰 지급

즉시 보상량과 지속시간은 `Map` 시트에서 관리한다.

## 5. 스테이지 테마

### 1단계 — 모래사막
평야 중심의 기본 환경. 최초 테스트 기준으로 자연 지형과 벌레지옥을 함께 배치한다.

### 2단계 — 빙하설원
자연 지형 비중을 증가시킨다. 현재 확정된 변경값은 자연 지형 30개이며 섹터 수와 세부 지형 크기는 미정이다.

### 3단계 — 화산지대
벌레지옥 비중을 증가시킨다. 현재 확정된 변경값은 벌레지옥 20개이며 섹터 수와 세부 배치 기준은 미정이다.

## 6. 데이터 기준

스테이지별 생성량, 최소 거리, 성소 생성 범위는 `Map` 시트에서만 수정한다.
