# 스테이지 및 웨이브 기획

## 1. 공통 시간 구조

한 웨이브는 전투 구간과 정비 구간으로 구성된다. 정비 중에는 빌더가 타워 관리와 연구소 준비를 수행하고, 러너의 외부 행동은 계속된다.

웨이브 시작 시각, 전투·정비 시간과 트랙 확장 시각은 `Global` 및 `Wave` 시트가 원본이다.

## 2. 1~7웨이브

현재 1~7웨이브의 등장 이벤트는 `Wave` 시트에 **개별 이벤트 단위**로 입력되어 있다. 기획서에서는 웨이브의 의도와 구조를 설명하고, 등장 시각·수량은 엑셀에서 확인한다.

- 1웨이브: 일반 몬스터 중심으로 시작하고 초반 정예를 추가한다.
- 2웨이브: 일반 몬스터의 묶음 규모를 늘리고 정예를 추가한다.
- 3웨이브: 시작 정예와 중반 일반 몬스터 이후 보스가 처음 등장한다.
- 4웨이브: 정예와 대량 일반 몬스터를 혼합한다.
- 5웨이브: 일반과 정예를 반복해 압박을 높인다.
- 6웨이브: 짧은 간격의 일반 몬스터와 정예·보스를 동시에 사용한다.
- 7웨이브: 시작 정예 대량 투입과 후반 추가 정예로 압박을 만든다.

## 3. 8~10웨이브

8~10웨이브의 구체적인 몬스터 종류·수량·등장 시각은 아직 기획자 답변이 없으므로 임의로 확정하지 않는다. `Wave` 시트에는 빈 행과 `추후 입력` 상태로 유지한다.

## 4. 트랙 확장

트랙은 정해진 시각에 단계적으로 확장한다.

1. 확장 5초 전 경고한다.
2. 확장 시 겹친 타워를 불능 상태로 만든다.
3. 해당 정비 시간에 한 번 무료 이전할 수 있다.
4. 다음 웨이브 시작 시까지 남아 있는 불능 타워는 파괴한다.

확장 시각과 단계는 `Wave` 시트에서 관리한다.

## 5. 난이도 변화

게임 진행 시간에 따라 외부 몬스터와 내부 몬스터의 압박 비중을 조정한다.

- 초중반: 외부 개척 압박을 완화하고 내부 웨이브를 강화한다.
- 중반: 외부 몬스터의 레벨 압박을 일부 낮추고 내부 웨이브와 무기 활용의 중요도를 높인다.
- 후반: 외부 압박을 다시 강화하고 후반 웨이브부터 내부 몬스터를 단계적으로 강화한다.

구체적인 강화폭은 아직 확정하지 않았으므로 수치 데이터로 임의 작성하지 않는다.

## 6. 데이터 운영

웨이브는 한 행을 한 번의 등장 이벤트로 관리한다. `웨이브 시작 + 웨이브 내부 시각 = 절대 등장 시각` 구조로 계산해 빠른 수정이 가능하도록 한다.
