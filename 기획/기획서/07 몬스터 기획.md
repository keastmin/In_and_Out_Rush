# 몬스터 기획

## 1. 분류

몬스터는 **외부 몬스터**와 **내부 몬스터**로 나뉜다.

### 외부 몬스터
개척지에서 러너와 사선을 위협한다.

- 기간티아: 배회형
- 스트라이더: 배회형
- 스토커: 추격형
- 라플라시아: 고정형

### 내부 몬스터
중앙 트랙을 따라 이동하며 러너와 타워를 직접 공격하지 않는다.

- 워커: 일반
- 프레데터: 정예
- 인베이더: 보스
- 하드워커: 특수 몬스터

실제 체력·이동속도·피해·보상 등 조정값은 `Monster` 시트가 원본이다.

## 2. 외부 몬스터의 영역 편입

라플라시아를 제외한 외부 몬스터가 영역에 편입되면 즉시 정예 내부 몬스터로 전환한다.

- 전투 중 편입: 내부 몬스터 소환 지점에서 즉시 등장
- 정비 중 편입: 다음 웨이브 시작 시 등장

기간티아를 최종 처치하면 토큰 1개를 획득한다. 기간티아 외 내부화 몬스터의 토큰 보상은 데이터 테이블의 확률값을 기준으로 한다.

## 3. 외부 몬스터

### 기간티아
개척지를 배회하는 대형 지네 형태의 몬스터다. 기본 이동속도보다 빠르게 움직이며 초·중·후반의 처치 난이도를 의도적으로 다르게 한다.

### 스트라이더
개척지를 배회하며 일정 거리를 순간적으로 슬라이드한다. 정지 후 재이동하는 패턴을 반복해 러너의 이동 경로를 방해한다.

### 스토커
러너를 추격하며 공격 시점의 러너 위치를 향해 직선 투사체를 발사한다. 투사체는 발사 당시의 목표 위치를 기준으로 이동한다.

### 라플라시아

라플라시아는 고정된 위치에 존재하는 탄막형 외부 몬스터다.

- 크기는 센터 타워와 동일한 지름 3타일 원형으로 취급한다.
- 일정한 순서로 투사체 패턴을 반복한다.
- 패턴 순서는 **8각 → 십자 4회 → X자 4회 → 회전 → 8각**이다.
- 8각은 8방향 동시 발사다.
- 십자는 + 형태 4방향 발사이며 각 발사 사이 간격을 데이터로 관리한다.
- X자는 X 형태 4방향 발사이며 각 발사 사이 간격을 데이터로 관리한다.
- 회전은 16방향을 순서대로 발사해 물결과 유사한 곡선을 만든다.
- 러너와 라플라시아가 맞닿으면 라플라시아는 영구적으로 투사체 공격을 멈추고 경직 상태가 된다.
- 이후 영역화하면 토큰 2개를 확정 획득한다.
- 단순히 영역화하는 경우에는 소멸하며 일반 내부 몬스터로 전환되지 않는다.

라플라시아의 패턴 세부 시간과 공격 수치는 `Monster` 시트에서 관리한다.

## 4. 내부 몬스터

### 워커
많은 개체 수로 웨이브 수량 압박을 만드는 기본형이다.

### 프레데터
높은 체력으로 타워의 화력을 오래 묶는 정예형이다.

### 인베이더
보스 웨이브의 핵심 몬스터다. 일반·정예와 달리 보스 전용 면역 규칙을 가진다.

### 하드워커
러너가 직접 전투에 가담하도록 유도하는 특수 몬스터다. 구체적인 전투 데이터는 추후 입력한다.

## 5. 실패 피해

- 일반 몬스터가 트랙을 완주하면 개체별 실패 피해를 적용한다.
- 정예 몬스터는 웨이브 종료까지 살아남은 개체의 피해를 합산한다.
- 보스 몬스터가 완주하면 러너 최대 체력에 비례한 피해를 적용한다.
- 피해 감소는 합산 및 비율 계산 뒤 최종 적용한다.

## 6. 반전

생화학 센터의 반전은 일반 몬스터에게만 적용된다.

- 반전된 몬스터는 기존 이동 방향을 유지한다.
- 별도의 공격 행동을 하지 않는다.
- 죽을 때까지 유지한다.
- 트랙을 완주하면 원래 몬스터가 주는 실패 피해량만큼 러너를 회복한다.
- 보스에는 적용되지 않는다.

## 7. 추가 세부 데이터

현재 상세 체력·직접 공격 피해·상태이상 저항은 아직 기획자 입력이 없다. 해당 값은 `Monster` 시트에서 `추후 입력` 상태로 유지하며 임의 확정하지 않는다.
