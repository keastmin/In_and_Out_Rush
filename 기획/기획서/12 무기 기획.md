# 무기 기획

## 공통 규칙

- 러너는 무기 한 종류만 1번 슬롯에 장착한다.
- 마우스 왼쪽 버튼으로 기본 공격하고 `Q`로 무기 특수 기능을 사용한다.
- 연구소에서 구매한 무기는 보급 타워를 통해 수령한다.
- 다섯 무기는 별도 해금 조건 없이 구매 목록에 등장한다.
- 기본 무기로 기간티아를 처치하는 목표 시간은 초반 1분 이상, 중반 1분 미만, 후반 약 30초다.
- 구매 비용과 피해량, 발사 간격, 탄창·장전, 사거리 등 조정값은 엑셀 `Weapon` 시트에서 관리하며 현재는 추후 입력 상태다.

## 쌍권총

- 빠르게 연속 공격하는 균형형 무기다.
- 특정 상황에 크게 약하지 않고 대부분의 전투에서 일정한 피해를 낸다.

## 산탄총

- 가까운 적에게 여러 탄환을 동시에 맞혀 큰 피해를 주는 근접형 무기다.
- 거리가 멀어질수록 효율이 크게 낮아진다.

## 석궁

- 한 발을 장전한 뒤 충전해 사용한다.
- 오래 충전할수록 강한 한 발을 발사하며 최대 충전 적중 시 대상을 밀어낸다.

## 유탄 발사기

- 포물선 궤도로 유탄을 발사한다.
- 정확한 궤도를 요구하는 고난도·고성능 무기로 운용한다.

## 화염 방사기

- 전방 범위에 지속 화염을 뿜는다.
- 여러 적이 모였을 때 범위 피해를 주는 데 특화한다.

## 문서와 데이터의 역할

이 문서는 기능의 목적, 작동 순서, 플레이 결과, 예외와 다른 기능과의 관계를 정의한다. 조정 가능한 수치·비용·확률·시간·수량은 문서에 중복 관리하지 않고 `데이터/땅타 프로젝트 데이터 테이블 0.60v.xlsx`의 해당 시트를 원본으로 사용한다.
