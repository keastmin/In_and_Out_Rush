# 러너 UI 기획

## 상시 정보

### 화면 중앙 상단

- 전체 게임 시간과 현재 외부 몬스터 난이도 단계를 표시한다.
- 난이도 상승 전에는 위험 상승을 미리 알린다.

### 화면 중앙

- 상호작용, 사선 위험, 구매와 보급 결과처럼 현재 행동에 필요한 문구를 표시한다.
- 여러 알림이 겹치면 생존에 직접 관련된 경고를 우선한다.

### 화면 오른쪽 상단

- 이번 판에서 획득한 광물, 가스와 토큰의 누적량을 구분해 표시한다.

### 화면 왼쪽 하단

- 현재·최대 체력과 변화 원인을 표시한다.
- 기력과 대시·슬라이드 사용 가능 여부를 표시한다.
- 1~4번 무기·아이템 슬롯에 수량, 선택 상태와 사용 불가 이유를 표시한다.
- 현재 스킬, 남은 재사용 시간과 기력 부족 여부를 표시한다.

## 개척 정보

- 개척 중 캐릭터 뒤쪽 중앙에 원반형 주파력 표시를 배치한다.
- 남은 개척 가능 거리와 탈진 상태 진입 시점을 공간적으로 보여준다.
- 탈진 상태에서는 총 이동속도가 50% 감소했다는 사실을 체력 피해와 혼동되지 않게 표시한다.
- 사선 피격, 자기 사선 접근과 생명선 자동 발동 가능 여부를 즉시 구분한다.

## 개별 화면

- `Space`: 중앙 연구소 반경 정보와 획득 유물 확인
- `F`: 보급·재생 타워 정보와 상호작용

## 경고 우선순위

1. 즉시 사망 위험
2. 주파력 소진과 사선 위험
3. 체력 위험
4. 보스·웨이브와 트랙 확장
5. 보급·아이템
6. 일반 안내

## 문서와 데이터의 역할

이 문서는 기능의 목적, 작동 순서, 플레이 결과, 예외와 다른 기능과의 관계를 정의한다. 조정 가능한 수치·비용·확률·시간·수량은 문서에 중복 관리하지 않고 `데이터/땅타 프로젝트 데이터 테이블 0.60v.xlsx`의 해당 시트를 원본으로 사용한다.
