# 공통 UI·UX 및 스마트 핑 기획

## 공통 표시 원칙

- 같은 자원, 몬스터, 타워와 상태는 러너·빌더 화면에서 같은 이름과 아이콘을 사용한다.
- 입력 불가 시 자원 부족, 거리 부족, 정비 시간 아님, 해금 전, 최대 보유 또는 잘못된 위치 등 이유를 표시한다.
- 트랙 확장, 웨이브 시작, 러너 치명 위험과 관문 활성화는 두 역할 모두에게 전달한다.
- 색상만으로 상태를 구분하지 않고 아이콘, 형태 또는 문구를 함께 사용한다.

## 알림 우선순위

1. 즉시 패배 또는 사망 방지 발동
2. 러너 체력·사선의 치명 위험
3. 트랙 확장과 웨이브 전환
4. 보스와 정예 생존 위험
5. 보급, 구매와 자원 획득
6. 일반 정보

## 공통 시간 안내

- 트랙 확장은 5초 전 메시지로 경고한다.
- 정비 종료와 새 웨이브 시작은 두 역할의 화면에서 동일한 기준 시각으로 표시한다.
- 스킬은 지속시간 종료 뒤부터 재사용 대기시간이 시작된다는 점을 남은 시간 표시로 구분한다.

## 스마트 핑의 기능 목표

스마트 핑은 두 플레이어가 음성 설명 없이 월드 위치와 요청을 공유하는 기능이다. 발신 역할, 대상 위치, 아이콘, 짧은 문구와 알림음을 함께 전달한다.

## 문서와 데이터의 역할

이 문서는 기능의 목적, 작동 순서, 플레이 결과, 예외와 다른 기능과의 관계를 정의한다. 조정 가능한 수치·비용·확률·시간·수량은 문서에 중복 관리하지 않고 `데이터/땅타 프로젝트 데이터 테이블 0.60v.xlsx`의 해당 시트를 원본으로 사용한다.
