유탄발사기 - 광역형 / 적을 뭉쳐서 날려버리는 무기 / 강점 - 광역, 다수 처리 / 약점 - 공격 빈도, 단일DPS



\*쌍권총



: 쌍권총은 무기 중 유일하게 달리면서 발사해도 패널티가 없어 기동성을 확보한 채 자유롭게 대상을 제압할 수 있는 무기이다. 

소형 단일 대상 몬스터를 상대하기에는 부족함이 없는 정도.



(공격력, 공격속도, 사거리는 표준 값으로 실제 수치가 아닌 상대적 계측 용도임, 이하 다른 무기의 해당 항목도 상대 값)

(모든 무기는 잔여 탄약이 있어도 재장전 가능)

(슬라이드 사용 시 무기 발사 불가, 스킬 및 아이템 별 사용 시에 상호 작용은 곧 추가)

(무기의 투사체는 커서의 방향으로 발사하되 허공이라면 최대 사거리까지 항상 도달)

(명중률은 100%면 회피율이 0%, 99%면 1% 확률로 대상이 회피\[miss] 가능)

(유탄발사기를 제외한 모든 무기의 투사체 속도는 즉발까진 아니어도 아주 빠르게)

\*산탄총



: 산탄총은 근접한 복수의 적을 상대하기에 최적의 무기로 대상이 아주 가깝다면 폭발적 데미지와 함께 약간의 넉백효과를 준다. 

반대로 거리가 떨어질수록 위력은 급감한다. 사거리 별 데미지 차이가 있으나 그렇다고 적을 찾아다니며 근접하기보단 일순간 가까워졌을 때 능동적으로 대처하기 위한 무기.



공격력 / 9, 7, 5 (사거리 0\~3, 3\~5, 5\~7)

공격속도 / 1

사거리 / 7

탄창 / 5발 (적립 식)

재장전 / 1초 (1발)

투사체 수 / 사격 당 10

명중률 / 100 (이동 시), 50 (달리기 시)

관통 / 없음

치명타 / 없음

특수효과 / 이동 중 사격 시 패널티 없음, 달리기 중 사격 시 명중률 저하, 3이내의 사거리에서 스토커나 스트라이더를 맞출 경우 작은 넉백 효과 (거리 1정도)



\*석궁



: 석궁은 다소 수동적이지만 강력한 한방 위력이 필요할 때 채택할 수 있는 무기다. 제 성능을 발휘하려면 풀차징과 함께 쏘는 순간은 멈춰서 발사해야하며 적중 시 큰 넉백효과를 준다.



공격력 / 120 (풀차징, 정지 시), 80 (풀차징, 이동 시), 50 (풀차징 전)

공격속도 / 차징 최대 1.5초

사거리 / 15

탄창 / 1발

재장전 / 3초

투사체 수 / 사격 당 1

명중률 / 100 (이동 시), 33 (달리기 시)

관통 / 모든 적 (풀차징, 정지 시), 없음 (풀차징 전 또는 이동 시)

치명타 / 없음

특수효과 / 차징은 제약없이 가능하며 풀차징에 멈춰서 발사할 경우 최대 데미지와 모든 적을 관통하며 사격한다. 이 때 스토커나 스트라이더를 맞출 경우 큰 넉백 효과를(거리 3 정도) 주고 

기간티아를 맞출 경우 1초 간 경직 효과를 준다. 이동하면서나 풀차징 전에 발사하면 관통이 사라지고 위력이 감소한다.



\*유탄발사기



: 유탄발사기는 일정 범위 내에 뭉쳐있는 적들을 상대하기에 제일 효율적인 무기로 준수한 데미지로 광역 공격을 시전한다.

투사체속도 / 1초에 4타일

공격범위 / 원형 3타일

사거리 / 8

탄창 / 1발

재장전 / 3초

투사체 수 / 사격 당 1

명중률 / 100 (이동 시), 75 (달리기 시)

관통 / 없음

치명타 / 없음

특수효과 / 이동 중 사격 시 패널티 없음, 달리기 중 사격 시 명중률 저하 (회피 여부는 개체 별로 계산)



강화가 존재함: 강화는 데이터시트의 Economy의 무기 업그레이드 항목을 참조함.



연구소에서 무기 종류를 드롭다운 형태로 개별적으로 구매하여 보급타워에 담아 보낼 수 있는 시스템이 존재함.



각 무기의 가격은 임의로 책정해주길 바람.



무기마다 고유한 스프라이트 이미지가 존재하여 러너의 현재 장착 무기 UI에 들어가거나 연구소에서 무기를 구매할 때 보여짐.



러너 UI에서 현재 보유 탄약, 현재 탄창 수가 보여질 예정.
